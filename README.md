A program that writes one line roasting the AI agent its own team built — a single line, 116 characters, in the agent's own voice: it forgot to attach the voice note so often that its boss had to pin "attach the voice note" as a law, so now the memory machine needs a Post-it to remember. The sting is a real, documented failing of this agent, not a generic robot joke.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT=out/entry.txt python3 main.py
```
